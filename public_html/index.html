What it is

A small media station that feels like an old TV.

Tater Tube turns a Raspberry Pi into a focused appliance. It hides the desktop, starts the app at boot, supports remotes and controllers, and keeps the interface tuned for repeat couch use.

Pi 4 CRT Appliance

Flash the NTSC or PAL composite image, wire the Pi to a CRT through the 3.5mm AV jack, and boot directly into the VCR-style UI.

CompositeArgon IRAnalog audio

Pi 5 HDMI Appliance

Use the HDMI auto image for modern screens. The image lets KMS choose the display's preferred EDID mode.

HDMI autoPi 54K displays

Modules

Everything lives behind the same VCR-style menu.

Each module is designed to launch cleanly from the main menu and return without showing the Linux desktop. Web Setup handles long-form configuration from a phone or computer.

Over The Air

Direct HDHomeRun playback with no guide screen. Pick OTA and it tunes like an old TV, with up/down channel changes and a channel OSD.

HDHomeRunLive TVOld-TV OSD

Video on Demand

Browse Emby, Jellyfin, or Plex libraries from a VCR-style interface with TV Mode, custom channels, no-repeat local commercials, and optional mid-roll breaks.

Emby/JellyfinMid-RollCustom Channels

Public Access

Save public YouTube playlists, browse videos from the couch, and run TV Mode with shuffled playlist channels and no-repeat local commercial categories.

YouTube Playlistsyt-dlpCommercials

Usenet

Browse media-only Newznab categories, search releases, view provider-supported trending, and hand selected NZBs to an AltMount/Stremio-compatible streamer.
